# Coding agents moved the bottleneck to CI

## Intended audience
Frontend and platform engineers, and engineering managers, whose teams are
adopting coding agents. Takeaway: when a machine writes the commits, the
constraint is verification, and a codebase with a real project graph is
better placed to handle it.

## Hook options
1. Coding agents didn't remove the bottleneck. They moved it to CI. — #11 Myth Bust; states the whole argument.
2. Your agent can write a feature in ten minutes. Your pipeline still takes forty. What do you fix? — #8 Question Trap; the numbers are illustrative, so they would need to be yours.
3. Faster code generation vs faster CI. I'd take the CI. — #12 The Comparison; opinionated, needs you to actually hold that view.

Recommended: 1, because it needs no number from you and reads like an
observation rather than a pitch.

## Body
```text
Coding agents didn't remove the bottleneck. They moved it to CI.

Juri Strumpflohner at Nx wrote earlier this month that agents push far more often than people do, and every push kicks off a CI run. Rachel Laycock, CTO at Thoughtworks, described a week where agents wrote all the code. The build was red a lot, and the team couldn't tell if it was agents colliding, weak module boundaries, or checks lagging behind the changes.

{{confirm: your own observation since moving your frontend work to Claude Code. Is the pipeline or the review queue the slow part now? One or two sentences, no internal numbers}}

What I like about the Nx post is that the answer isn't "buy bigger runners". It's knowing the codebase well enough to run less. Only what a change affects. Cached where nothing changed. E2E split per test file so it spreads across machines. It's a vendor writing about its own product, so read the benchmark numbers with that in mind.

Years ago I moved a monolithic Angular app into an Nx monorepo because it was hard to maintain. I didn't think the project graph would end up being what keeps CI affordable once a machine is writing the commits.

Where's your bottleneck now: writing, reviewing, or waiting for green?
```
